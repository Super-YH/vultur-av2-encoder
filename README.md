# Vultur / AV2 Encoder

Vultur is a high-speed AV2 encoder featuring 10 presets, numbered 0 through 9.

Compared to `avmenc` (`cpu-used=6`), Vultur offers estimated speedups ranging from approximately **10× to 500×** across its presets, using conservative estimates.

The source code will be released once the specifications are sufficiently finalized, to avoid confusion and inconsistencies during development.
